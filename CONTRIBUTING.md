# Contributing

**Issues are welcome.** Bug reports, unclear instructions, a skill that misled your agent, or a rule that turned out to be wrong: open an issue and say what you ran and what happened.

**Pull requests are not being accepted for now.** A pull request will be closed without review. If you have a fix, describe it in an issue instead. This may change later.

**Security problems go through private reporting, not issues.** See [SECURITY.md](SECURITY.md).
