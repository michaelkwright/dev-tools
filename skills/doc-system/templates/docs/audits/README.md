# Audits

Seeded from dev-tools @ {{DEV_TOOLS_SHA}}; this file is now the project's own.

Point-in-time investigations, one file each, named `<topic>-<YYYY-MM-DD>.md`: what was examined, how, what was found, and when. An audit is true only as of its date, so it is never rewritten to stay current; add a dated addendum instead, and re-verify any live figure before reusing it. Its conclusions move elsewhere once acted on: settled design into `docs/decisions/`, unbuilt work into `ROADMAP.md`, shipped behavior into `PRODUCT_SPEC.md`.
